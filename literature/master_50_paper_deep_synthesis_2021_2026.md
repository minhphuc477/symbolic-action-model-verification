## I. Detailed Synthesis of Landmark Papers (2021–2026)

### 1. [arXiv:2607.14169] When a Verified World Model Still Loses: Play-Adequacy vs Prediction-Accuracy in LLM-Synthesized Code World Models
- **Author**: Javier Aguilar Martín (AGILabs)
- **Venue & Date**: `arXiv:2607.14169` (July 2026)
- **Full Text Source**: [2607.14169_fulltext.md](file:///f:/Thesis/papers/2607.14169_fulltext.md) (43 pages)
- **Core Scientific Discovery**:
  - Demonstrates the **Verified-vs-Correct Gap**: Code World Models (CWMs) synthesized by LLMs can pass a trajectory sampling gate at **100% transition accuracy** and $\ge 98\%$ state accuracy on the planner's visited distribution, yet lose **100% of play trials** because the $<1\%$ error region contains pivotal dynamics.
  - Isolated Play Cost: $B = 0.091$ (seed-clustered $95\%\text{ CI }[0.065, 0.117], n=4800$ over 20 seeds).
- **Mathematical Law of Danger**:
  $$\text{danger} = \text{play\_cost} \times (1 - \text{rarity})^N$$
  where $\text{rarity}$ is the probability a random playthrough triggers the omitted rule, and $N$ is the sampling gate size. The $(1-\text{rarity})^N$ factor is proven exact for i.i.d. Bernoulli sampling.
- **Rule Translation vs Rule Inference**:
  - LLM synthesis behaves as **rule translation** from prompt context rather than **rule inference** from transition data.
  - Scaling to GPT-5.x (mini and large) and applying off-policy DAgger (naive DAgger, proper DAgger, targeted on-manifold examples) **fails to infer unmentioned pivotal rules**.
- **Imperfect Information Coverage Bound**:
  - A random size-$N$ gate is identifying for the belief-inference function when $N \gtrsim b^{d_{\max}}$. Explains why shallow games (Kuhn poker) pass, whereas deep games (Leduc poker) require policy-guided or adversarial search.
  - Minimal witness **Beacon**: Passes sampling gate (0/8156 mismatches) yet loses 100% of games (0.000 vs 0.500 fair baseline).
  - Replaced by a single policy-guided held-out trace, the gate changes verdict from accept (0/8156) to reject (4/8190).

### 2. [arXiv:2607.29218] MirrorCraft: Paired Evaluation under Hidden Rule Changes in Minecraft
- **Authors**: Jianxin Gao, Beini Hu, Runze Li, Wanli Peng, Ruohan Lei, Jinyuan Zhang, Linna Deng, Tianyi Yu, Zining Wang
- **Venue & Date**: `arXiv:2607.29218` (July 2026)
- **Full Text Source**: [2607.29218_fulltext.md](file:///f:/Thesis/papers/2607.29218_fulltext.md) (24 pages, 19 figures)
- **Core Scientific Discovery**:
  - Introduces **MirrorCraft**: A paired benchmark evaluating LLM agents in Minecraft under server-side datapack rule modifications.
  - Keeps terrain, spawn, resource placement, objective, interface, and action budget matched between Vanilla and Mirror worlds; only server-side rules change.
  - Defines the **Rule Intervention Effect (RIE)**:
    $$\text{RIE} = \text{Score}_{\text{Vanilla}} - \text{Score}_{\text{Mirror}}$$
- **Empirical Findings**:
  - High agent performance on fixed mechanics reflects pretraining priors rather than online causal inference.
  - Among un-guided configurations, ReAct achieves the highest pooled Mirror score.
  - Providing exact text rule descriptions yields only modest gains across 3 progression objectives, proving text descriptions without active execution feedback fail to solve zero-shot rule transfer.

### 3. [arXiv:2609.09163] World-Time Compute with Verified Code World Models
- **Authors**: James Schwoebel et al. (Quome Inc., Univ. of Washington, OWASP, IEEE Computer Society)
- **Venue & Date**: `arXiv:2609.09163` (September 2026)
- **Full Text Source**: [2609.09163_fulltext.md](file:///f:/Thesis/papers/2609.09163_fulltext.md) (37 pages, 17 figures)
- **Core Scientific Discovery**:
  - Introduces **World-Time Compute** (the training-time counterpart of test-time compute): Fine-tuning LLMs on exactly-labeled trajectories generated by executable code world models.
  - Code world models authored via `OpenWorld` stay **100% exact over 20-step rollouts** and 10x out-of-distribution probes, whereas neural LLM state prediction and trained MLPs accumulate error and collapse.
  - Fine-tuning on 128 disjoint worlds generalizes to unseen held-out worlds, reaching **40% success vs 6%** for corrupted-label controls (+34-point exactness-gated lift, CI [29, 39]).

### 4. [arXiv:2604.24062] Grounding Before Generalizing: How AI Differs from Humans in Causal Transfer
- **Authors**: Liangru Xiang, Yuxi Ma, Zhihao Cao, Yixin Zhu, Siyuan Zhu
- **Venue & Date**: `arXiv:2604.24062` (April 2026)
- **Full Text Source**: [2604.24062_fulltext.md](file:///f:/Thesis/papers/2604.24062_fulltext.md) (7 pages)
- **Core Scientific Discovery**:
  - Demonstrates that humans adapt zero-shot to rule interventions (>85% success) within 1–2 trials by forming structural causal hypotheses, whereas LLMs drop below 30% accuracy due to pretraining prior over-reliance.
  - Proves LLMs require initial environmental grounding before decontextualized structural causal transfer can occur.

### 5. [arXiv:2402.12275] WorldCoder: Building World Models via Code Generation for Model-Based LLM Agents
- **Authors**: Mukul Sikka, Ankit Sharma, et al.
- **Venue & Date**: `NeurIPS / ICLR` (arXiv:2402.12275, 2024/2025)
- **Full Text Source**: [2402.12275_fulltext.md](file:///f:/Thesis/papers/2402.12275_fulltext.md) (65 pages, 42 figures)
- **Core Scientific Discovery**:
  - Synthesizes Python code world models from trajectory interactions and searches over them using classical planners (MCTS / BFS).
  - Demonstrates that representing transition dynamics as executable code enables zero-shot lookahead planning in complex text and grid environments, outperforming direct LLM policies by wide margins.
