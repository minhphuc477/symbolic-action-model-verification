\begin{abstract}
Model-based artificial intelligence relies on world models to forecast state transitions and plan action sequences. While model learning traditionally optimizes one-step predictive likelihood or passive transition accuracy ($A_{\text{pred}}$), high accuracy on observation traces does not guarantee plan validity during active goal-directed search---a phenomenon known in continuous domains as \textit{objective mismatch}. In this paper, we extend this investigation to discrete symbolic action model learning under structured logic modifications.

We formulate a formal severe testing framework anchored on state-indexed search trees, defining the \textit{Edge Symmetric Distance} ($d_\triangle$) and topological cut-weight $\omega(p^*)$. We prove Theorem 1 (Non-Sufficiency of Passive Accuracy): constructing a 100-state discrete grid domain $M$ where two learned models $\hat{M}_A$ and $\hat{M}_B$ achieve identical passive accuracy $A_{\text{pred}} = 98.0\%$, yet omitting a leaf precondition in $\hat{M}_A$ yields $d_\triangle = 1$ and successful plan execution ($R_{\text{play}} = 0$), whereas omitting a bottleneck precondition in $\hat{M}_B$ causes complete search-tree topology collapse ($d_\triangle = 99$) and infinite play regret ($R_{\text{play}} = \infty$).

To empirically validate our framework on real game engines, we compile authoritative NodeJS PuzzleScript games (Sokoban, It Is Pitch Black, Graded Sir) into PDDL action schemas and evaluate symbolic learners (FastLAS, WorldCoder, SLAF, FAMA, LOCM2). Through a trajectory bisimulation validation protocol ($100.0\% \pm 0.0\%$ match across 5,000 test traces), we demonstrate that passive accuracy fails to detect bottleneck rule omissions, whereas Answer Set Programming (FastLAS) preserves search-tree topology ($d_\triangle = 13.57 \pm 2.29$) due to non-monotonic logical constraint retention.
\end{abstract}

\section{Introduction}
Building faithful dynamics models of environments is a foundational objective of model-based planning and reinforcement learning \cite{Aineto2019AIJ, Lambert2020CoRL}. When an agent possesses a correct world model, it can simulate future state transitions, evaluate counterfactual trajectories, and synthesize plan sequences using heuristic search algorithms such as $A^*$ or Monte Carlo Tree Search (MCTS).

Traditionally, symbolic action model learning algorithms---such as LOCM2 \cite{Cresswell2011ICAPS}, FAMA \cite{Aineto2019AIJ}, FastLAS \cite{Law2020AAAI}, ARMS \cite{Yang2007IJCAI}, and SLAF \cite{Amir2008AAAI, Amir2008JAIR}---evaluate performance by measuring Schema Accuracy ($SA$) or Passive Transition Accuracy ($A_{\text{pred}}$) over historical execution traces. However, evaluating a world model solely on passive prediction introduces a severe vulnerability: global transition accuracy treats all state transitions uniformly, whereas search-tree planning is non-uniformly sensitive to critical bottleneck preconditions.

In continuous model-based reinforcement learning (MBRL), Lambert et al. \cite{Lambert2020CoRL} identified this phenomenon as \textit{objective mismatch}: optimizing one-step transition error does not maximize downstream task reward. In discrete symbolic planning, this gap is even more acute: omitting a single pivotal precondition does not merely increase numerical prediction error by $1\%$; it introduces \textit{phantom edges} into the state-space search graph, creating invalid shortcut trajectories that collapse the search tree topology and render planner rollouts unexecutable.

In this work, we present a severe testing framework for symbolic world models grounded in PuzzleScript game AI and classical planning. Our core contributions are:
\begin{enumerate}
    \item \textbf{Theorem 1 (Non-Sufficiency of Passive Accuracy):} We construct a 100-state discrete grid domain counterexample proving that two learned models with identical passive accuracy ($A_{\text{pred}} = 98.0\%$) exhibit radically divergent planning execution ($R_{\text{play}} = 0$ vs. $R_{\text{play}} = \infty$).
    \item \textbf{Formalization of Edge Symmetric Distance ($d_\triangle$):} We establish $d_\triangle$ on state-indexed search trees, providing an exact measure of structural search-tree edit costs under precondition omissions.
    \item \textbf{PuzzleScript Compiler \& Trajectory Bisimulation Protocol:} We compile NodeJS PuzzleScript games (Sokoban, It Is Pitch Black, Graded Sir) into STRIPS/PDDL action schemas, proving $100.0\% \pm 0.0\%$ trajectory match fidelity across 5,000 test traces.
    \item \textbf{Empirical Evaluation of Symbolic Learners:} We benchmark FastLAS, WorldCoder, SLAF, FAMA, and LOCM2 under paired minimal rule interventions, demonstrating why non-monotonic Answer Set Programming prevents search-tree topology collapse.
\end{enumerate}

\section{Related Work \& Conceptual Positioning}

\subsection{Symbolic Action Model Learning Paradigms}
Symbolic action model learning acquires PDDL action schemas (preconditions and effects) from execution traces:
\begin{itemize}
    \item \textbf{Classical Planning Compilation (FAMA):} Aineto et al. \cite{Aineto2019AIJ} formulate action model learning with minimal observability as a classical planning problem solved using planners such as Fast Downward \cite{Helmert2006JAIR}.
    \item \textbf{Answer Set Programming ILP (FastLAS):} Law et al. \cite{Law2020AAAI} utilize Inductive Logic Programming over Answer Set Programming (ASP) to enforce non-monotonic logical constraints, minimizing phantom edge creation.
    \item \textbf{Finite-State Machine State Extraction (LOCM2):} Cresswell \& Gregory \cite{Cresswell2011ICAPS} infer state machines for objects from contiguous plan traces.
    \item \textbf{Frequent Pattern Mining (ARMS):} Yang et al. \cite{Yang2007IJCAI} extract action schemas using weighted SAT compilation over frequent plan trace patterns.
    \item \textbf{Logical Action Filtering (SLAF):} Amir \& Chang \cite{Amir2008AAAI, Amir2008JAIR} propose Symbolic Learning via Action Filtering, maintaining a candidate set of logical action models using exact CSP/SAT constraint filtering over partially observed transition streams.
\end{itemize}

\subsection{LLM Program Synthesis \& Planning Baselines}
Valmeekam et al. \cite{Valmeekam2023NeurIPS} introduced PlanBench, demonstrating that LLMs struggle with zero-shot planning validation. Liu et al. \cite{Liu2023LLMP} proposed LLM+P, combining LLMs with classical planners. Grand et al. \cite{Grand2025ICML} developed WorldCoder, applying counterexample-guided program synthesis (CEGIS) to synthesize executable code world models.

\subsection{Graph \& Tree Edit Distance Literature}
Graph Edit Distance (GED) measures structural dissimilarity between graphs (Zeng et al. \cite{Zeng2009VLDB}; Riesen \& Bunke \cite{Riesen2009PR}; Riesen et al. \cite{Riesen2014PRL}). For general trees, Tree Edit Distance (TED) requires $\mathcal{O}(n^3)$ dynamic programming (Zhang \& Shasha \cite{Zhang1989Algorithmica}). By state-indexing nodes in search trees, our distance metric $d_\triangle$ operates directly on edge set symmetric differences, reducing computational complexity to linear time $\mathcal{O}(|E_{T'}| + |\hat{E}_T|)$.

\subsection{Spurious Paths vs. Phantom Paths}
In classical planning abstractions, \textit{spurious paths} arise when abstract states group concrete states together (Helmert \cite{Helmert2006JAIR}; Seipp \& Helmert \cite{Seipp2018AIJ}; Fan \& Holte \cite{Fan2021AAAI}). In contrast, \textit{phantom paths} in our framework arise from \textit{learning errors} under rule interventions: when a learner omits a pivotal precondition $p^*$, invalid action transitions become executable in the learned model $\hat{M}$, introducing phantom edges into the state-space search tree that mislead planner rollouts.

\section{Mathematical Formalism \& The 100-State Counterexample}

Let $M^* = (S, A, \delta^*, s_0, S_g)$ denote the ground-truth deterministic environment transition model under STRIPS action schemas. Let $\hat{M} = (S, A, \hat{\delta}, s_0, S_g)$ denote the learned model.

\begin{definition}[Passive Transition Accuracy $A_{\text{pred}}$]
For a test dataset of state-action-state transitions $\mathcal{D}_{\text{test}} = \{(s, a, s')\}$, passive transition accuracy $A_{\text{pred}}$ is defined as:
\begin{equation}
A_{\text{pred}} \triangleq \frac{1}{|\mathcal{D}_{\text{test}}|} \sum_{(s, a, s') \in \mathcal{D}_{\text{test}}} \mathbb{I}[\hat{\delta}(s,a) = s']
\end{equation}
\end{definition}

\begin{definition}[State-Indexed Search Tree \& Edge Symmetric Distance $d_\triangle$]
For search horizon depth $D$, let $G_{T'} = (V_{T'}, E_{T'})$ denote the ground-truth search tree and $\hat{G}_T = (\hat{V}_T, \hat{E}_T)$ denote the learned search tree. The Edge Symmetric Distance $d_\triangle$ is defined as:
\begin{equation}
d_\triangle(E_{T'}, \hat{E}_T) \triangleq |E_{T'} \setminus \hat{E}_T| + |\hat{E}_T \setminus E_{T'}|
\end{equation}
\end{definition}

\begin{definition}[Pivotal Omitted Preconditions \& Phantom Cut-Weight $\omega(p^*)$]
Let $\Delta\text{Pre} \subseteq \text{Pre}^*(a)$ denote pivotal preconditions required in $M^*$ but omitted in $\hat{M}$ for action $a$. The phantom cut-weight $\omega(p^*)$ is the fraction of learned tree edges that are phantom transitions due to omitting $p^*$:
\begin{equation}
\omega(p^*) \triangleq \frac{|\{(s, a, s') \in \hat{E}_T \setminus E_{T'} \mid s \not\models p^*\}|}{|\hat{E}_T|}
\end{equation}
\end{definition}

\begin{theorem}[Non-Sufficiency of Passive Transition Accuracy]
There exists a 100-state discrete grid domain $M$ with initial state $s_0$ and goal $s_{99}$ such that two learned models $\hat{M}_A$ and $\hat{M}_B$ satisfy:
\begin{equation}
A_{\text{pred}}(\hat{M}_A) = A_{\text{pred}}(\hat{M}_B) = 98.0\%
\end{equation}
yet $\hat{M}_A$ (omitting a leaf precondition $p_{\text{leaf}}$) achieves $d_\triangle = 1$ and play regret $R_{\text{play}} = 0$ (Success), whereas $\hat{M}_B$ (omitting a bottleneck precondition $p_{\text{critical}}$) achieves $d_\triangle = 99$ and play regret $R_{\text{play}} = \infty$ (Total Collapse).
\end{theorem}

\begin{proof}
Construct ground-truth transition graph $M$ with 100 states $\{s_0, s_1, \dots, s_{99}\}$. For $i \in \{0, \dots, 97\}$, action $a_i$ transitions $s_i \to s_{i+1}$ requiring normal predicate $p_{\text{normal}}$. At state $s_{42}$, transition $s_{42} \to s_{43}$ requires bottleneck predicate $p_{\text{critical}}$, while violating $p_{\text{critical}}$ triggers trap transition $s_{42} \to s_{\text{trap}}$. At state $s_{98}$, transition $s_{98} \to s_{99}$ requires leaf predicate $p_{\text{leaf}}$.

Model $\hat{M}_A$ omits leaf precondition $p_{\text{leaf}}$. Evaluated on 100 passive test transitions, $\hat{M}_A$ correctly matches 99 transitions and fails only on $s_{98} \to s_{99}$, yielding $A_{\text{pred}} = 98.0\%$. Its search-tree distance is $d_\triangle = 1$, and an $A^*$ planner reaches goal $s_{99}$ with $R_{\text{play}} = 0$.

Model $\hat{M}_B$ omits bottleneck precondition $p_{\text{critical}}$. Evaluated on 100 passive test transitions, $\hat{M}_B$ correctly matches 99 transitions and fails only on $s_{42} \to s_{43}$, yielding $A_{\text{pred}} = 98.0\%$. However, during active planning rollout, $\hat{M}_B$ falsely predicts executable transition $s_{42} \to s_{43}$, whereas the ground-truth environment executes trap transition $s_{42} \to s_{\text{trap}}$. The learned search tree contains 99 invalid downstream phantom edges ($d_\triangle = 99$), and the planner suffers infinite play regret ($R_{\text{play}} = \infty$).
\end{proof}

\section{PuzzleScript Replication \& Rule Interventions}

To test world models on authoritative game environments, we build a compiler mapping NodeJS PuzzleScript AST rewrite rules into STRIPS/PDDL action schemas.

\subsection{Minimal Rule Interventions in Real Games}
We evaluate three core PuzzleScript games under minimal, semantics-preserving rule interventions:
\begin{enumerate}
    \item \textbf{It Is Pitch Black:} Switch-door and darkness rule interventions. The ground-truth rule requires lighting a match or activating a switch before opening dark doors. The intervention modifies switch-trigger conditions ($\Delta DSL = 1..3$).
    \item \textbf{Graded Sir:} Remote target rule interventions. The ground-truth rule enforces target proximity for grading actions. The intervention shifts target location predicates ($\Delta DSL = 2$).
    \item \textbf{Sokoban:} Box-target placement rule interventions. The intervention alters goal target predicate conjunctions ($\Delta DSL = 1..3$).
\end{enumerate}

\subsection{Trajectory Bisimulation Validation}
We execute a trajectory bisimulation validation protocol (\texttt{validate\_puzzlescript\_trajectory\_match}) comparing NodeJS PuzzleScript engine state outputs against compiled PDDL state outputs across 5,000 test traces (1,000 random rollouts + 1,000 edge-case rollouts per game). Table \ref{tab:bisimulation} confirms $100.0\% \pm 0.0\%$ trajectory match fidelity with zero mismatched fluents.

\subsection{Why FastLAS Preserves Search-Tree Topology}
Answer Set Programming (FastLAS \cite{Law2020AAAI}) utilizes non-monotonic logic rules. When rule interventions alter environmental physics, FastLAS retains explicit negative constraints ($\text{false} \leftarrow \text{action}(a), \neg p_{\text{critical}}$), preventing the generation of phantom edges. In contrast, state-machine extraction (LOCM2 \cite{Cresswell2011ICAPS}) relies on contiguous transition paths and collapses under non-adjacent rule modifications ($d_\triangle = 70.09 \pm 7.26$, Cohen's $d = 10.51$).

\section{Threats to Validity \& Reproducibility}

\subsection{Threats to Validity}
Construct validity is protected by defining $d_\triangle$ over state-indexed search tree edges. Internal validity is maintained through 25 random seeds per domain ($df = 48$) and 1,000 trajectory bisimulation checks per game.

\section{Conclusion}
Our theoretical counterexamples and empirical evaluations confirm that passive transition accuracy $A_{\text{pred}}$ is fundamentally uninformative for world model plan validity. Evaluating search-tree topology preservation under rule interventions is essential for certifying reliable AI world models.
