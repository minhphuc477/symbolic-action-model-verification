### [L457] A Survey of World Model Benchmarks (2026)
- **Tạp chí / Hội nghị**: `2026`
- **Lĩnh vực / Area**: `World-model benchmark survey / evaluation validity`
- **Phương pháp (Key Method / Setting)**:
  Surveys 102 representative benchmarks and organizes evaluation by capability target, protocol, metric family and data source.
- **Kết quả thực nghiệm (Key Evidence / Results)**:
  World-model evaluation is already a broad, rapidly formalizing benchmark field; metric/protocol claims need precise coordinates.
- **Giới hạn & Điều kiện biên (Limitations & Boundaries)**:
  Does not identify mechanic-controlled planning-burden-matched instance synthesis as an occupied benchmark class in the current audit.

### [L424] XGuardian: Towards Generalized, Explainable and More Effective Server-side Anti-cheat in First-Person Shooter Games (2026)
- **Tạp chí / Hội nghị**: `USENIX Security 2026`
- **Lĩnh vực / Area**: `Anti-cheat / cross-game generalization / explainability`
- **Phương pháp (Key Method / Setting)**:
  USENIX Security 2026 system uses server-side pitch/yaw trajectory features and a GRU-CNN with SHAP-style explanation. Main CS2 data cover 3,069,216 aiming operations, 31,971 trajectories and 5,486 players; generalization is evaluated across CS2, CS:GO/HAWK data and Farlight84, with public datasets/artifacts.
- **Kết quả thực nghiệm (Key Evidence / Results)**:
  Cross-game generalization, large-scale real-world validation, explainability and some adversarial robustness in FPS anti-cheat are directly occupied.
- **Giới hạn & Điều kiện biên (Limitations & Boundaries)**:
  Temporal calibration/false-positive drift after patches or legitimate meta/style changes is not the core evaluation.

### [L430] GameWorld: A Dynamic Benchmark for Generalist Agents in Interactive Game Environments (2026)
- **Tạp chí / Hội nghị**: `arXiv 2026`
- **Lĩnh vực / Area**: `General game agents / interactive benchmark / evaluation protocol`
- **Phương pháp (Key Method / Setting)**:
  GameWorld evaluates generalist agents on 34 browser games and 170 tasks using both low-level Computer-Use and semantic Generalist interfaces, state-verifiable progress/success metrics, a paused sandbox, and a real-time track. Full-paper audit shows interface choice can reverse relative model ordering; memory/context effects also differ by interface.
- **Kết quả thực nghiệm (Key Evidence / Results)**:
  Large multi-game generalist-agent evaluation is current and state-verifiable; generic 'build a game-agent benchmark' is occupied.
- **Giới hạn & Điều kiện biên (Limitations & Boundaries)**:
  The paper measures repeat-run robustness but does not formalize measurement invariance or ranking robustness across interface, latency regime, action budget, reset policy, scoring rule, memory harness and task mixture.

### [L436] The SIDO Performance Model for League of Legends (2024)
- **Tạp chí / Hội nghị**: `2024`
- **Lĩnh vực / Area**: `Esports analytics / skill measurement / longitudinal stability`
- **Phương pháp (Key Method / Setting)**:
  Hierarchical Bayesian LoL performance model explicitly evaluates metric discrimination, independence and stability. It states that stability should assure a metric measures the same thing from patch to patch, then compares rankings from patches 13.6-13.9 versus 13.14-13.18 using concordance indices.
- **Kết quả thực nghiệm (Key Evidence / Results)**:
  Patch-to-patch stability of esports performance metrics is directly occupied.
- **Giới hạn & Điều kiện biên (Limitations & Boundaries)**:
  Concordance cannot identify whether rank change is true player-skill change or a patch-induced change in the measurement function/construct. No explicit measurement-invariance or scale-linking test is reported.
